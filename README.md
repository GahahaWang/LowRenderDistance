# LowRenderDistance

Lets you set Minecraft's Render Distance and Simulation Distance as low as **1 chunk**. The vanilla minimums are 2 and 5.

Works in both the vanilla Video Settings and [Sodium](https://modrinth.com/mod/sodium).

Also supports [Bobby](https://modrinth.com/mod/bobby)

## Notes

- The lower the Simulation Distance, the closer to you mobs, crops, and redstone machines stop running, which can break farms.
- On multiplayer servers, the server decides the Simulation Distance, so this setting only applies to singleplayer worlds.
- With Render Distance at 1, only 1 chunk is drawn, but the game still loads chunks within a radius of 2.
